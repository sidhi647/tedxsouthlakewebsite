# TEDxSouthlake Website

The official website for TEDxSouthlake, built with [Next.js](https://nextjs.org).

## Getting Started

Install dependencies and run the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it.

## Content

Most site content (event details, speakers, board members, partners) lives in `lib/data.ts`. Photos live under `public/`.

## Deploy

This project deploys cleanly to [Vercel](https://vercel.com/new) with zero configuration.
